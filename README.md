# Interactive Alarm Clock

사용자가 조작할 수 있는 알람시계 웹 프로젝트

## 폴더 구조
- `index.html` : 시계 3D 외형, 조작 버튼, 상태창 및 7-세그먼트 디스플레이 마크업
- `css/style.css` : 2계층 디자인 토큰(`:root`), BEM 네이밍, 알람 깜빡임·진동 애니메이션 스타일
- `js/script.js` : 배터리 방전 타이머, Set 버튼 단계별 설정·조회, Web Audio 비프음 및 초기화 로직

## 기능
- **버튼(`Set`, `▲`, `▼`, `◯`) -> 알람 설정/확인**
    - `Set`로 모드 설정
      - Set 1회: 현재 시간 설정
      - Set 2회: 알람 설정(최대 3개, 00:00:00 설정 불가)
        - 알람 울림: 설정된 알람 시간 도달 시 큰 화면 깜빡임 + 시계 전체 진동 +  전자음 발생 (아무 버튼이나 클릭 시 즉시 정지).
      - Set 3회: 설정된 알람 확인 
    - `▲ / ▼`로 숫자 조절 및 알람 선택
    - `◯`로 확인 및 다음 단계로 넘어감
   
- **소형 디스플레이**
    - **배터리: 배터리 상태 표시**
      - 시계 시작 시 배터리는 `100%`이며, `1초`마다 `1%`씩 감소
      - 배터리가 `0%`가 되면 디스플레이가 어두워지며 방전
    -  **알람: 알람 상태 표시**
        - 알람이 저장된 경우 확인할 수 있음(설정 되지 않은 경우 00:00:00으로 저장)

- **대형 디스플레이**
  - 시-분-초 단위 표시 
  - 시각(알람) 설정 조작 화면

- **배터리 함**
    - 배터리가 `0%`로 방전되거나 문 여는 홈을 클릭하면 배터리함 덮개가 열리며 즉시 방전됨 (방전시 전체 초기화)
    - 방전된 상태에서 열린 배터리함(건전지) 클릭하면 배터리가 `100%`로 충전되며 초기 상태에서 재시작
    - 배터리함의 넓은 부분 클릭시 배터리가 `100%`로 충전
